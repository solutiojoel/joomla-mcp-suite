# KB — Project Closeout

Steps to complete when closing out a new site or redesign project.

---

## In SBS

- Confirm a date is in the **Launch** field.
- Verify the **Launched Checklist** is complete.
- Remaining scrum points = **0**.
- Clear the **Project Caution** and **Project Warning** fields (yellow field).
- Set Project Phase to **Finished**.

## On the Site

- If the site has multiple domain names, links between subsites must use **absolute URLs** (full domain name), not relative paths.
- For redesigns: update control panel icons to SVGs (only blocked if the site is still on the Moria server).
- For redesigns: confirm that administrators have access to **Redirects**, **User Logs**, and **Quick Galleries**.

## In Google Calendar

- If the site is a paid account, confirm via contract whether 3 months of unlimited support applies before paid support begins.
- Add a **"Paid Support Begins"** item to the Solutio B/S Calendar with a notification 2–3 weeks prior so the appropriate person can email the client a reminder.

## Dropbox

- Move the client folder from **Working Sites** to **Archive Sites** in Content Dropbox (or leave for Jackie to complete).

## User Email Lists

- Users should be added to the **Email Lists Spreadsheet** so Lori can add them to MailChimp.

## Client Notification

- When notifying the client of launch, also remind them they can cancel website hosting services with their existing provider when ready.
